# 通用增量文件同步工具

一套基于 HTTP 的轻量级增量文件同步工具，由服务端与客户端两部分组成。
服务端把本地的一个或多个目录（称为「数据集」）以只读方式提供出来，
客户端比对后只下载缺失或内容不一致的文件。

适用于把一台机器上的数据目录分发到多台机器，例如内网资料镜像、
素材包分发、构建产物下发等场景。

- 运行期零第三方依赖，只用 Python 标准库
- 全程以 SHA-256 做内容比对，下载后二次校验
- 所有接口均需访问令牌
- 支持相对路径与绝对路径配置
- 可用 PyInstaller 打包成单文件程序

## 工作原理

```
         服务端                                客户端
   ┌──────────────────┐                  ┌──────────────────┐
   │ 启动时扫描数据集  │                  │  读取 config.ini  │
   │ 逐文件算 SHA-256  │                  └────────┬─────────┘
   │ 生成清单存入内存  │                           │
   └────────┬─────────┘                           │
            │        ①  POST /register            │
            │ ◀───────────────────────────────────┤
            │        ②  GET /snapshot             │
            ├───────── 返回文件清单 ──────────────▶│
            │                                     │ ③ 与本地文件比对
            │        ④  GET /files/...            │   找出差异
            │ ◀───────────────────────────────────┤
            ├───────── 返回文件内容 ──────────────▶│ ⑤ 校验 SHA-256
            │                                     │   通过后落盘
   └──────────────────┘                  └──────────────────┘
```

服务端在启动时一次性生成清单并缓存在内存中，因此后续请求不会重复
扫描磁盘。数据集内容变动后需要重启服务端以刷新清单。

## 环境要求

Python 3.8 或更高版本。无需安装任何第三方库。

```bash
python --version
```

## 快速开始

下面以本机演示为例，服务端与客户端都在同一台机器上。

### 1. 准备服务端

```bash
cd server
python sync_server.py
```

首次运行会提示配置文件不存在，并自动生成一份 `server_config.ini`，
其中已经填好一个随机令牌。打开该文件，把数据集的 `location`
改成你真实的数据目录：

```ini
[server]
host = 127.0.0.1
port = 8000
token = 自动生成的随机令牌
log_downloads = true

[my-dataset]
location = D:\data\my-dataset
include_dirs =
exclude_dirs =
```

记下 `token` 的值，稍后客户端要用到。然后重新启动：

```bash
python sync_server.py
```

看到类似下面的输出即表示启动成功：

```
[*] 通用增量文件同步工具 - 服务端已启动
[*] 监听地址: http://127.0.0.1:8000
[*] 已加载 1 个数据集:
      - my-dataset: 128 个文件, 256.40 MB
```

### 2. 准备客户端

另开一个终端：

```bash
cd client
python sync_client.py
```

同样会自动生成 `config.ini`。打开后填写三项：

```ini
[server]
url = http://127.0.0.1:8000
token = 粘贴服务端生成的令牌
dataset = my-dataset
timeout = 30
retries = 3

[local]
download_dir = data
client_name =
```

不确定数据集名称时可以先查询：

```bash
python sync_client.py --list
```

### 3. 执行同步

先看看有哪些差异，不实际下载：

```bash
python sync_client.py --check
```

确认无误后正式同步：

```bash
python sync_client.py
```

```
[1/4] 正在连接服务端并校验访问令牌...
      服务端响应: 注册成功

[2/4] 正在获取文件清单...
      服务端清单包含 128 个文件

[3/4] 正在校验本地文件...
      已是最新: 120 个
      需要同步: 8 个

[4/4] 开始下载 8 个文件(合计约 16.20 MB)...
    (1/8) A001/data.bin [本地缺失, 2.10 MB]
    ...

[*] 同步完成: 成功 8 个, 失败 0 个
[*] 所有文件均已通过 SHA-256 校验。
```

再次运行时，已经同步过的文件会被跳过。

## 客户端命令行参数

| 参数 | 说明 |
| --- | --- |
| 无参数 | 执行正常的增量同步 |
| `--check` | 只检查差异并列出清单，不下载任何文件 |
| `--list` | 列出服务端所有可用的数据集 |
| `--force` | 忽略本地已有文件，重新下载全部内容 |
| `--help` | 查看帮助 |

## 配置项说明

### 服务端 `server_config.ini`

`[server]` 段：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `host` | `127.0.0.1` | 监听地址。`0.0.0.0` 表示允许局域网访问 |
| `port` | `8000` | 监听端口 |
| `token` | 自动生成 | 访问令牌，至少 16 个字符 |
| `log_downloads` | `true` | 是否记录每次文件下载 |

其余每个段代表一个数据集，段名即客户端使用的数据集名称，
只允许字母、数字、点、下划线和连字符：

| 配置项 | 说明 |
| --- | --- |
| `location` | 数据集在服务端的真实目录，支持相对与绝对路径 |
| `include_dirs` | 只同步名称匹配该正则的一级子目录，留空表示全部 |
| `exclude_dirs` | 要排除的一级子目录名，逗号分隔，留空表示不排除 |

过滤规则示例：

```ini
# 只同步 A001、A002 这类目录，但排除 A000
include_dirs = ^A\d+$
exclude_dirs = A000

# 同步整个目录下的所有内容
include_dirs =
exclude_dirs =

# 只同步 assets 和 config 两个子目录
include_dirs = ^assets$, ^config$
exclude_dirs =
```

### 客户端 `config.ini`

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `url` | `http://127.0.0.1:8000` | 服务端地址，需含协议和端口 |
| `token` | 无 | 访问令牌，须与服务端完全一致 |
| `dataset` | 无 | 要同步的数据集名称 |
| `timeout` | `30` | 单个请求的超时秒数 |
| `retries` | `3` | 单文件下载失败后的重试次数 |
| `download_dir` | `data` | 本地同步目录，不存在时自动创建 |
| `client_name` | 本机名 | 客户端标识，仅用于服务端日志 |

## 接口说明

所有接口（除 `/healthz`）都需要携带访问令牌，可通过请求头
`X-Auth-Token` 或查询参数 `token` 传入。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/register` | 上报客户端信息，便于服务端日志审计 |
| `GET` | `/datasets` | 列出可用数据集及其文件数、总大小 |
| `GET` | `/snapshot?dataset=<名称>` | 获取指定数据集的文件清单 |
| `GET` | `/files/<数据集>/<相对路径>` | 下载单个文件 |
| `GET` | `/healthz` | 健康检查，无需令牌 |

用 curl 验证：

```bash
curl -H "X-Auth-Token: 你的令牌" http://127.0.0.1:8000/datasets
curl "http://127.0.0.1:8000/healthz"
```

## 局域网部署

把服务端配置中的 `host` 改为 `0.0.0.0`，并在防火墙放通对应端口：

```ini
[server]
host = 0.0.0.0
port = 8000
```

Windows 下放通端口（需管理员权限）：

```powershell
New-NetFirewallRule -DisplayName "FileSync" -Direction Inbound `
  -Protocol TCP -LocalPort 8000 -Action Allow
```

客户端把 `url` 指向服务端的局域网 IP：

```ini
url = http://192.168.1.10:8000
```

## 安全说明

请在部署前了解以下几点。

**传输为 HTTP 明文。** 令牌和文件内容都不加密。仅建议在可信的内网
环境中直接使用。如需暴露到公网，请在前面套一层 Nginx、Caddy 之类的
反向代理并启用 HTTPS，不要把本服务直接开放到公网。

**令牌是唯一的访问控制手段。** 没有用户体系，也没有按数据集分权。
持有令牌即可读取所有已配置数据集。令牌请使用足够随机的字符串：

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

**服务端只提供读取，不接受上传。** 下载接口只允许取用启动时登记在
清单内的文件，并且会对最终路径做目录归属校验，无法通过构造
`../` 之类的路径读取数据集之外的内容。扫描阶段也会跳过指向目录外的
符号链接。

**客户端会校验服务端返回的路径。** 文件清单来自服务端，客户端不会
无条件信任：任何绝对路径、带盘符、含 `..` 段的条目都会被拒绝，
并确认最终落盘位置在 `download_dir` 之内。文件先写入临时文件，
SHA-256 校验通过后才原子替换到目标位置，因此中断不会留下残缺文件。

即便如此，客户端仍然会把服务端给出的文件写入本地磁盘。请只连接
你自己信任的服务端。

**配置文件不要提交到仓库。** `config.ini` 和 `server_config.ini`
含有令牌和本机真实路径，已在 `.gitignore` 中排除。仓库里只保留
`*.ini.example` 示例文件。

## 打包为可执行程序

```bash
pip install -r requirements-dev.txt

cd server
pyinstaller --onefile --console sync_server.py

cd ../client
pyinstaller --onefile --console sync_client.py
```

产物在各自的 `dist/` 目录下。程序会把 `.exe` 所在目录作为相对路径的
基准目录，因此把配置文件和 `.exe` 放在一起即可。

打包后的程序会在启动时把控制台代码页切换为 UTF-8，中文提示可以正常
显示，不需要手动执行 `chcp 65001`。

打包产物请作为 GitHub Releases 的附件发布，不要提交进仓库。
PyInstaller 的单文件产物常被杀毒软件误报，分发时建议同时提供源码
运行方式。

## 常见问题

**启动时提示「没有任何可用的数据集」**

配置中所有数据集的 `location` 都不存在或不是目录。检查路径拼写，
相对路径是相对于配置文件所在目录，而不是当前工作目录。

**客户端提示「访问令牌不正确」**

两端的 `token` 不一致。注意不要把注释或引号一起复制进去，
也留意首尾空格。

**客户端提示「服务端没有配置名为 xxx 的数据集」**

`dataset` 的值必须与服务端配置里的段名完全一致，区分大小写。
执行 `python sync_client.py --list` 查看可用名称。

**数据集里加了新文件，客户端却同步不到**

服务端的清单是启动时生成并缓存的。数据变动后需要重启服务端。

**清单里的文件数比实际少**

检查 `include_dirs` 和 `exclude_dirs`。默认模板只同步形如 `A001`
的一级子目录并排除 `A000`；要同步全部内容就把两项都留空。

**同步很慢**

每个文件都要计算 SHA-256，首次全量校验在文件多时较耗时。之后的
增量同步会先用文件大小快速筛查，只在大小一致时才计算哈希。

**端口被占用**

换一个 `port`，或先排查占用进程：

```powershell
Get-NetTCPConnection -LocalPort 8000 | Select-Object OwningProcess
```
